TPX1000 一覽頁狀態過濾修正版
================================

新增位置
--------
「一覽」頁搜尋工具列正下方：
[全部] [未讀＋複習] [未學習] [要複習] [已習得]

核心邏輯
--------
- 未讀＋複習：狀態空白 或 review
- 未學習：狀態空白
- 要複習：review
- 已習得：ok
- 全部：不套用狀態條件

行為
----
- 狀態可以和目前書籍分類、搜尋文字疊加使用。
- Chip 數量依「目前書籍＋目前分類」即時計算，搜尋文字不改變 Chip 基礎數量。
- 手機版可水平滑動，不壓縮搜尋框。
- 點右側狀態圓圈後，數量立即更新；若項目不再符合目前狀態，立即移出清單。
- 每本書、每位使用者獨立記憶上次狀態過濾。
- 無結果時顯示「顯示全部」。
- 進度頁的未學習、複習、已習得數字可直接跳到一覽頁對應狀態。
