TPX1000 V3.2 更新說明
=====================

本版處理兩個實際遇到的錯誤：
  生成失敗：HTTP 429 You exceeded your current quota
  生成失敗：Load failed

一、這兩個錯誤的原因
--------------------
HTTP 429
  不是程式壞掉，是 Gemini 免費層配額用完。
  Google 在 2025 年 12 月大幅削減免費額度，
  gemini-2.5-flash 的每日請求數從約 250 次降到 20 至 50 次。
  配額是綁在 Google Cloud 專案上，不是綁在 API key，
  所以同一個專案下再開幾支新 key 也不會增加額度。
  每日配額以太平洋時間午夜重置，換算台灣時間約為下午四點。

Load failed
  這是 Safari 的網路層錯誤訊息，代表 fetch 根本沒送出或中途斷掉。
  已確認不是 Service Worker 造成：
  sw.js 的 fetch 攔截本來就會跳過非 GET 與跨網域請求。
  常見原因是 iOS 切換網路、連線不穩、或請求逾時。

二、新增 Gemini 傳輸層 KIN_GM
-----------------------------
所有 Gemini 呼叫改走同一層，含閃卡補充、測驗與 AI 記憶輔助。

1. 自動重試
   網路錯誤與 5xx 伺服器錯誤會自動重試最多 3 次，
   採指數退避，間隔 0.7 秒、1.4 秒。
   Load failed 這類暫時性斷線多半第二次就會成功。

2. 逾時中止
   以 AbortController 設定 45 秒逾時，
   避免請求卡住不回應，畫面一直停在「產生中」。

3. 模型備援
   主要模型 gemini-2.5-flash 撞到配額時，
   自動改用 gemini-2.5-flash-lite 重試一次。
   兩者額度分開計算，flash-lite 的每日上限明顯較寬鬆。

4. 配額冷卻
   收到每日配額用盡的 429 之後，會暫停呼叫 30 分鐘，
   避免一直撞牆而讓狀況更糟。
   每分鐘限流的 429 則依 Google 回傳的 retryDelay 決定等待秒數。

三、錯誤訊息改為看得懂的中文
----------------------------
原本直接把英文 JSON 倒在畫面上，現在改成：

  429 每日配額
    今日免費配額已用完。
    免費額度以太平洋時間午夜重置，約為台灣時間下午四點。
    可改用其他金鑰，或到 Google AI Studio 開啟付費方案。

  429 每分鐘限流
    呼叫太密集，已超過每分鐘上限。
    約 54 秒後可再試。

  403
    金鑰無效或未啟用 Generative Language API，請到使用者專區重新設定。

  404
    找不到指定模型，可能名稱已變更或該帳號無權使用。

  5xx
    Google 伺服器暫時異常，稍後再試。

  網路錯誤
    連線失敗，請確認網路後再試一次。

四、關於圖片配額
----------------
圖片使用 gemini-2.5-flash-image，配額與文字模型分開計算。
不同資料來源對這個模型的免費額度說法不一致，
有的列為每日 500 張，有的列為免費層不開放，
實際額度請以 Google AI Studio 顯示的專案即時限額為準。

五、驗證結果
------------
index.html 共 23 段 inline JavaScript，node --check 全部通過，0 錯誤。
sw.js 語法檢查通過。
錯誤訊息轉換以 429 每日、429 每分鐘、403、404、500 五種情境實測通過。
Load failed 與 AbortError 均能正確辨識為網路錯誤並觸發重試。
