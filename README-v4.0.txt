TPX1000 V3.2 → V4.0 完整更新
================================

本包包含 V3.2、V3.3、V4.0 的累積更新。

V3.2 出題品質
---------------
- 聽力題只顯示中文選項，禁止英文答案穿幫。
- 智慧近義干擾項：同詞性、同級別、同章節、中文語意與英文字形評分。
- 拼字第一次答錯後顯示近音辨識提示，再聽一次重新輸入。
- review、不熟詞義、低熟練度及 relapse 單字加權優先出題。

V3.3 AI 錯題分析
------------------
- 測驗結果頁新增「請 AI 分析本次測驗」。
- 傳送題型、總題數、答對／答錯、提示數、錯題單字、詞義、詞性與級別。
- Gemini 回傳：本次診斷、主要弱點、優先複習、下一輪建議。
- 分析結果保存於 kinQuizAi:<使用者>，最多保留最近 50 次。
- 未設定 Gemini API Key 時自動隱藏按鈕。

V4.0 AI TOEIC 實戰教練
------------------------
- 使用收藏單字生成 TOEIC Part 6／7 風格短文。
- 產生英文、繁中翻譯、情境標籤與使用單字清單。
- 可沿用 Cloud TTS 逐句朗讀與同步高亮，作為聽力情境練習。
- 可針對生成文章建立理解測驗，形成閱讀＋聽力＋測驗流程。
- 內容保存於既有 AI 教練歷程，最多保留最近 30 筆。

部署

覆蓋 index.html、sw.js、roadmap.json，commit、push。

- Cloud TTS Key：使用者專區 → Cloud TTS
