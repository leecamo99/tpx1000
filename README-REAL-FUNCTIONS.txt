TPX1000 V3.1–V4.x 真正功能版
================================

這一版不是只改 Roadmap。所有功能均接到可見 UI。

立刻可見的入口
---------------
打開「測驗」後，最上方新增橘框：
  V3.1–V4.0 功能中心
  [AI 實戰教練] [匯入 JSON 題庫]

V3.1 驗收流程
--------------
1. 開始任一測驗並答一題。
2. 回饋區點「解說」。
3. 解說頁底部會出現「返回第 N 題」。
4. 返回後題號、分數、作答結果保持不變。
5. 完成測驗後，結果頁會看到「完整檢討」。
6. 可切換「全部／只看答錯」。
7. 每題都有：查看解說、重做此題、加入弱點。
8. 查看解說後可按「返回完整檢討」。

V3.3 驗收流程
--------------
1. 完成測驗。
2. 結果頁一定會看到「請 AI 分析本次測驗」。
3. 未設 Key 時按鈕文字會明示「先設定 Gemini Key」。
4. 有 Key 時會送出題型、分數、提示數、錯題字義與級別。
5. 結果保存於 kinQuizAi:<使用者>，最近 50 次。

V4.0 驗收流程
--------------
1. 測驗設定頁點「AI 實戰教練」。
2. 頁面標題為「V4.0 AI TOEIC 實戰教練」。
3. 可用收藏字生成「閱讀／聽力情境」。
4. 可用 TTS 逐句朗讀並同步高亮。
5. 可生成 TOEIC 模擬測驗。

V4.x 驗收流程
--------------
1. 測驗設定頁點「匯入 JSON 題庫」。
2. 選擇本包的「題庫格式範例.json」。
3. 系統驗證 options 與 answer，成功後直接加入 AI 教練歷程並開題。

部署
----
覆蓋 index.html、sw.js、roadmap.json。
Service Worker 版本：kin-shell-v12。
部署後若測驗頁頂部沒有「V3.1–V4.0 功能中心」，表示仍是舊快取：
設定 → Safari → 進階 → 網站資料 → 刪除 leecamo99.github.io，再重開。
