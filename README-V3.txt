TPX1000 V3 更新說明
===================

一、閃卡例句簡短化
------------------
1. Gemini 補充閃卡的提示詞改為：英文例句 5 到 10 個單字，最多 12 個單字，
   僅用一個主要子句，禁止關係子句、分號、破折號、括號，不使用人名公司名日期，
   長度與單字書的短例句相當。
2. 中文翻譯同樣維持一句短句。
3. 新增前端守門 __kinTrimEx()：若 Gemini 仍回傳超過 12 個單字的句子，
   會自動保留含目標單字的主要子句，切掉附加子句後補回句點。
   實測：15 字 -> 8 字、13 字 -> 5 字，原本就夠短的句子不動。
4. 已存在的舊閃卡不會被改寫，只有新產生或按下重補時才套用。

二、我的筆記 AI 記憶輔助
------------------------
1. 單字詳情的「我的筆記」下方新增「AI 記憶輔助」區塊。
2. 按下按鈕後由 Gemini 產生四項助記內容：
   字根拆解、聯想記憶、易混字比較、記憶圖像描述。
3. 結果存進 localStorage，key 為 kinMnemo:<使用者>，
   以「書籍/單字ID」分開儲存，同一個字不會重複呼叫 API。
4. 三個操作按鈕：
   加入筆記 - 把字根、聯想、易混字寫進我的筆記，沿用原本自動儲存
   重新生成 - 重新呼叫 Gemini
   刪除助記 - 二次確認後刪除，不會動到你自己寫的筆記
5. 沿用使用者專區既有的 Gemini 金鑰，不需另外設定。

三、一併修復
------------
1. index.html 內殘留的 3 組 Git 合併衝突標記已清除，
   保留較新的簡單模式與防歧義選項版本。
   衝突標記會讓瀏覽器整段 JavaScript 停止執行，
   造成閃卡新增、編輯、檢視等功能失效。
2. Service Worker 快取版本 kin-shell-v13 -> kin-shell-v14。

四、驗證結果
------------
index.html 共 21 段 inline JavaScript，node --check 全部通過，0 錯誤。
sw.js、books.js 語法檢查通過。
例句縮短邏輯以 5 組樣本實測通過。
