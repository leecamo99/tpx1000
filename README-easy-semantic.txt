TPX1000 簡單模式近義選項修正版
================================

問題範例
--------
以下中文意思過於接近，不應同時出現在簡單模式：
- 預測、預報
- 假定、推測
- 預期、期待
- 要求、規定

本次修正
--------
1. 新增中文語意群。相同語意群的字不得互相當簡單模式選項。
2. 新增中文字義重疊門檻，即使不在人工群組，高度重疊仍排除。
3. 中翻英簡單模式排除拼字過近的英文單字。
4. 簡單模式優先不同詞性及不同語意類別。
5. 排除後不足三個干擾項，就跳過該題，不勉強出題。

內建語意群包含：
預測/預報/推測/預估/估計/預見
假定/假設/設想/推定/認定
預期/期待/期望/盼望
要求/規定/命令/請求/需求
允許/准許/許可/同意

增加/提高/提升/增長/上升

確認/證實/查明/核實
通知/告知/通報/宣告
