TPX1000 — 三檔更新包
====================

直接覆蓋到專案根目錄，然後 git add . && git commit && git push

  index.html      主程式（含詞義級 SRS ＋ roadmap／devtools 入口）
  sw.js           Service Worker（VER 已升 kin-shell-v5）
  devtools.html   音檔核對工具（開發者模式）

--------------------------------------------------
注意：roadmap 需要另外兩個檔
--------------------------------------------------
index.html 裡有「開發進度表」連結，指向 roadmap.html。
如果你還沒上傳過這兩個檔，點進去會 404：

  roadmap.html
  roadmap.json

不影響其他功能，音檔核對照常可用。

--------------------------------------------------
音檔核對怎麼用
--------------------------------------------------
網址：https://<你的帳號>.github.io/<repo>/devtools.html
App 入口：使用者專區 → 開發進度 → 音檔核對

1. 上方篩選選「含括號」，只有 16 筆，先掃這批
2. 點音檔按鈕試聽
3. 標記 正確 / 錯位 / 只唸一半 / 沒聲音 / 其他
4. 標記非「正確」時會展開輸入框，寫下實際聽到什麼
   （這欄比勾選更有用，我能據此推算偏移量）
5. 按「匯出偵錯表」，複製 JSON 或下載檔案回報

鍵盤快捷鍵：空白播放、1~5 標記、↑↓ 上下筆

--------------------------------------------------
最快的單點確認
--------------------------------------------------
如果只想先解 C-010 microwave (oven)，聽一個檔就夠：

  播 C-011_w.mp3，聽它唸的是 oven 還是 refrigerator

  唸 oven         → audioFix 修正表整段要往前挪一格
  唸 refrigerator → 只有 C-010 單獨壞掉，補一筆就好
